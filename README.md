# Q-Management-System

A simple queue management system built using Python and SQLite.
This project helps manage customer queues using tokens, making the process more organised and easier to handle.
### Features
- User registration and login
- Admin login
- Automatic token generation
- Join and check queue status
- Call the next customer
- Complete service
- No-show management
- View queue history

### Built With
- Python
- SQLite3

### Run the Project
```bash
python main.py
```
